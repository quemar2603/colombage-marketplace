Soft rounded chip for tagging services, categories or statuses.

```jsx
<Badge tone="pink">Compagnie</Badge>
<Badge tone="success" dot>Confirmé</Badge>
```

Tones: `pink` (default), `navy`, `peri`, `neutral`, `success`, `warning`, `danger`. Add `dot` for a status indicator. Always pill-shaped; pink is the house accent for separating service categories.
